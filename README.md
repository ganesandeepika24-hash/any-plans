# London Plans

new project Any Plans? Create a React + Vite + Tailwind + shadcn/ui app called “Any Plans?”. The home page has a heading, a short line “Find something to do in London”, and a placeholder search bar that does nothing yet. Use a single page with a light theme. Don’t add a backend or any API calls.
